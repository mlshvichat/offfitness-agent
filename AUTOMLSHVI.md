# Автопубликации @automlshvi

Бот: @mlshvibot (название владельца: mlshviauto). Токен хранится только в
GitHub Actions Secret AUTO_TELEGRAM_BOT_TOKEN. GEMINI_API_KEY используется общий.
Модель генерации и проверки: gemini-3-flash-preview; полный облачный preview,
права бота и 31 тест успешно проверены 3 ноября 2026 года, run 41641321169.

Расписание: 09:00, 14:00, 19:00 Europe/Moscow. Живая отправка разрешена владельцем.
GitHub Actions работает без компьютера владельца, возможны задержки расписания.
Публикуются только посты, прошедшие проверки. При ошибке запуск сообщает о сбое.

Тематика: выбор новых авто и владение, аудитория Петербурга с интересом к Omoda,
Jaecoo и Belgee. Пока нет проверяемого прайса и источника предложений, запрещены
конкретные цены, ставки, акции, наличие и характеристики моделей.
Не генерируются клиентские истории или гарантии одобрения кредита.
Посты предлагают практические действия и вопросы покупателю.

Последние 30 постов импортируются из публичного канала при пустом журнале.
Они используются только для повторов и стилистики, не как действующие предложения.
Новые отправки записываются в data/automlshvi-history.json. Журнал доставок не обрезается.
Отдельные файлы out/auto-preview.txt и out/auto-editorial-report.json не отправляются
в Telegram. До трёх правок; после каждой заново проверяются содержание и стиль.

Ручные режимы в AUTOMLSHVI Posts: preview без отправки; test в отдельный канал,
который задаётся секретом AUTO_TEST_CHAT_ID. Проверяются ID и права бота.
С реального канала не выполняются повторные тестовые отправки.
Для остановки отключите AUTOMLSHVI Posts или установите LIVE_APPROVED=False в auto_agent.py.
Оба канала используют общую очередь публикаций для предотвращения конфликтов
записи истории в main, но отдельные журналы, проверки бота и токены.
