# OFFFITNESS Agent

Редактор русского фитнес-канала на GitHub Actions и Gemini API.

## Статус публикаций

Владелец подтвердил автопубликацию 3 ноября 2026 года. После проверки реальной
генерации и редакторского контроля включены три запуска GitHub Actions:
09:00, 14:00 и 19:00 Europe/Moscow (06:00, 11:00, 16:00 UTC).
Компьютер владельца и рабочие сессии ChatGPT для запуска не требуются.
Действуют отдельные ограничения Gemini API и GitHub Actions.

LIVE_APPROVED=True разрешает публикации; workflow передаёт LIVE_ENABLED=true
только для события schedule. Ручные режимы preview и test сохранены.
Чтобы остановить отправку, установите LIVE_APPROVED=False или отключите workflow.
GitHub может задерживать запуски; спустя два часа после слота отправка запрещена.
Пост с ошибкой проверки пропускается, повторной попытки отправки нет.

## Редакторский контроль

Каждый сгенерированный пост проходит проверку безопасности, стиля и повторов.
Используются собственные русские редакторские инструкции с опорой на
[Wikipedia:Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).
Это ориентиры качества, а не определение авторства или «процент ИИ».

Проверяются штампы, преувеличения, искусственные противопоставления, эмодзи,
однообразная композиция, заголовки и финалы. Модель получает содержание и
стилевые признаки 30 последних отправленных постов из data/history.json.
У старых записей признаки вычисляются при чтении. Сам журнал доставок не
обрезается: он нужен для защиты от повторной отправки и спорных доставок.

При стилистических замечаниях текст бережно переписывается максимум три раза.
После каждой правки заново проверяются безопасность, стиль, повтор темы и
сохранение смысла относительно исходника. Сомнительные фитнес/медицинские
утверждения, повтор темы, изменение смысла, ошибочный ответ или недоступность
проверки блокируют публикацию. Неудачный запуск Actions сообщает об ошибке.
Проверка моделью снижает риск, но не гарантирует фактическую корректность.

Замечания, изменения, этап сбоя и результат сохраняются отдельно в
out/editorial-report.json и артефакте offfitness-editorial-report на 7 дней.
Отчёт не отправляется в Telegram и не включается в текст поста или журнал.
Доступ к артефактам определяется правами GitHub; это не секретное хранилище.

## Тестирование

Локальные тесты без API и Telegram:

    python -m unittest discover -s tests -v

Те же тесты выполняются при push и pull request. Для проверки реальной модели:
Actions → OFFFITNESS Posts → Run workflow → preview.
Предпросмотр не отправляет сообщения и не добавляет запись в память публикаций.
Он сохраняет одобренный текст в артефакте offfitness-preview.

Режим test отправляет только одобренный пост в отдельный тестовый канал.
Проверяется личность бота, право публикации и несовпадение канала с @offfitness
по username и числовому ID. Успешные тестовые отправки входят в память.
До отправки обязательно сохраняется резервирование в main; при конфликте
изменений отправка блокируется. Неопределённую доставку не повторяют автоматически.
Для тестовой отправки используйте main после слияния.

Секреты GitHub Actions:

- GEMINI_API_KEY — ключ Gemini.
- TELEGRAM_BOT_TOKEN — токен @offfitness_editor_bot.
- TEST_CHAT_ID — ID отдельного закрытого тестового канала.

Не записывайте ключи в репозиторий. Для preview достаточно GEMINI_API_KEY.

Рабочая модель: gemini-3.5-flash. Реальный облачный preview с проверками безопасности
и редакторского качества успешно выполнен 3 ноября 2026 года (Actions run 41636947209).
